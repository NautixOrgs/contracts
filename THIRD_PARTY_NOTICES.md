## Reference implementation (MIT)

This repository is a re-implementation of a shielded-pool protocol. Its own contracts are original code. The protocol design, and the structure of `circuits/transact.circom`, `src/Pool.sol` and `src/Registry.sol`, follow an MIT-licensed reference implementation published at <https://github.com/CellaFinance/cella>. What was taken over is the protocol: the note, commitment and nullifier constructions, the set of public signals, the auditor record, the function signatures and the events.
